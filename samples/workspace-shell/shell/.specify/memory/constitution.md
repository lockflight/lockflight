# Acme Workspace Constitution

## Core Principles

### I. Contracts first
Public API and message contracts change only through a reviewed spec; consumers are listed in the spec.

### II. Tests accompany behaviour
Every behaviour change ships with tests in the service that owns it.

### III. Small services, explicit ownership
Each service repository has one owning team; cross-service features list every repository they touch.

## Governance
This constitution supersedes local habits. Amendments are recorded in this file with a date.
